# Cognee Admin

Cognee 知识引擎管理工具 — CLI + HTMX Web 管理面板。

## 组件

| 组件 | 目录 | 说明 |
|------|------|------|
| **CLI** | `cli/` | Rust CLI + Web 面板 — 单二进制双模式（serve + client） |

## 安装

```bash
cd cognee-admin/cli
cargo install --path .
```
